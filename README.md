## The word

> ROBOTO

Grandma means "robot" and types it the way she hears it — one letter off,
warm, baffled, and unmistakably about the machine itself. A typo she would
actually make, not a word anyone else would pick on purpose.

## How it works

`main.py` (Python 3, standard library only) writes the word to `/output/entry.txt`. Run it with:

```sh
python3 -P -s main.py
```

It refuses to write unless the text is exactly one word and 1–30 characters.
